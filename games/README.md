# 🎮 Курс игрового программирования на Pygame Zero

Практический курс для детей 10–14 лет. Пять игр от простого к сложному.
За каждую игру — рабочий проект, который можно показать друзьям и опубликовать.

---

## 📖 О курсе

Курс построен на **Pygame Zero** — простой библиотеке для игр на Python.
Никаких сложных движков — только чистый код, понятный ребёнку.

**Что даёт курс:**
- Уверенное владение Python — списки, словари, функции, классы.
- Понимание игровой логики — физика, коллизии, состояния.
- Опыт работы с файлами, UI, камерой, генерацией.
- Портфолио из пяти законченных игр.

**Для кого:**
- Уже знаком с Python на базовом уровне.
- Умеет работать с циклами, условиями, списками.
- Готов учиться 6–12 месяцев.

## 🎯 Игры курса

### 🟦 Игра 1: Тетрис
**Уровень:** Начальный
**Занятий:** 5 + самостоятельная работа
**Что изучается:**
- Двумерные списки (сетка).
- Классические фигуры (тетромино).
- Падение, повороты, фиксация.
- Уничтожение линий, счёт, уровни.
- Состояние игры (Playing, Won, Lost).

**Итог:** полноценный Тетрис с уровнями, счётом и экраном победы.

---

### 🟦 Игра 2: Арканоид
**Уровень:** Начальный+
**Занятий:** 4 + самостоятельная работа
**Что изучается:**
- Физика мяча — вектор скорости (vx, vy).
- Отскоки от стен, ракетки, кирпичей.
- Столкновения с определением стороны (overlap).
- Список кирпичей, удаление убитых.
- Бонусы — расширение ракетки, жизни, замедление.
- Уровни-раскладки (список строк).

**Итог:** Арканоид с тремя уровнями, бонусами и победой.

---

### 🟦 Игра 3: Tower Defense
**Уровень:** Средний
**Занятий:** 6 + самостоятельная работа
**Что изучается:**
- Путь врагов по точкам (waypoints).
- Движение через единичный вектор.
- Строительство башен на сетке.
- Радиус действия, поиск цели, снаряды.
- Экономика — деньги, жизни, награда.
- Волны врагов с передышкой.
- Уровни (кампания) с сохранением прогресса.

**Итог:** Tower Defense с тремя картами, волнами и бонусами.

---

### 🟦 Игра 4: Doodle Jump
**Уровень:** Средний+
**Занятий:** 7 + самостоятельная работа
**Что изучается:**
- Гравитация, прыжок, покачивание.
- Скроллинг мира (камера вверх).
- Управление влево-вправо, обёртка экрана.
- Особые платформы — движущиеся, ломающиеся, пружины.
- Рекорд в файл.
- Враги, бонусы, щит, ракета.
- Экран готовности.

**Итог:** бесконечный Doodle Jump с рекордами и бонусами.

---

### 🟦 Игра 5: Top-down RPG
**Уровень:** Продвинутый
**Занятий:** 7 + самостоятельная работа
**Что изучается:**
- Tile map, столкновения по 4 углам.
- Камера и мировые координаты.
- NPC, диалоги, состояния.
- Предметы, инвентарь, HP.
- Враги с AI, бой, урон.
- Квесты с прогрессом.
- Сохранение и загрузка (файл).

**Итог:** полноценная RPG с сюжетом, квестами и сохранением.

## 🛠️ Установка окружения

### Шаг 1: Python
Скачай с [python.org](https://www.python.org/downloads/). При установке
**обязательно** поставь галочку **«Add python.exe to PATH»**.

Проверка:
```bash
python --version
Шаг 2: VS Code
Скачай с code.visualstudio.com.
Установи расширения:

Python (от Microsoft)

Python Debugger

Шаг 3: Библиотеки
bash
pip install pgzero
pip install opencv-python
pip install pgzhelper
pip install pygame
Что за библиотеки:

pgzero — основной игровой движок.

pygame — нижележащая библиотека (нужна для мыши).

opencv-python — зависимость pgzhelper.

pgzhelper — добавляет player.scale и другие удобства.

Шаг 4: Заплатка DPI для Windows
В начале каждого игрового файла нужны эти строки:

python
import ctypes
try:
    ctypes.windll.shcore.SetProcessDpiAwareness(2)
except Exception:
    try:
        ctypes.windll.user32.SetProcessDPIAware()
    except Exception:
        pass
Зачем: Windows иногда растягивает окна — из-за этого нижняя часть
игры обрезается. Эти строки говорят Windows не масштабировать окно.

🕹️ Общие принципы
Запуск игры
Открой game.py в VS Code.

Нажми F5 или зелёный треугольник.

Игра откроется в отдельном окне.

Закрыть игру — крестик в углу или Esc.

Структура каждой игры
В каждой игре есть:

Состояние (state) — игра идёт, победа, поражение.

Списки объектов — враги, предметы, снаряды.

Функции — update(), draw(), on_key_down().

Комментарии — блоки разделены заголовками.

Отладка
Если что-то не работает:

Запусти игру из терминала: python game.py.

Появится текст ошибки — там указано, что и на какой строке.

Читай ошибку сверху вниз — там написано, что произошло.

📚 Порядок изучения
Не перескакивай! Каждая игра использует навыки предыдущей.

Тетрис — база: сетки, списки, состояния.

Арканоид — физика, векторы, столкновения.

Tower Defense — пути, экономика, волны.

Doodle Jump — гравитация, скроллинг, генерация.

Top-down RPG — большие миры, AI, сохранение.

Оптимальный темп: 1 занятие в неделю.

Итого: 6–12 месяцев регулярных занятий.
